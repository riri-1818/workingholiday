渡航後の実務

myGov登録とTFN(税番号)申請、働き始める前にやっておくべき理由

最終更新日: 2026年8月30日

この記事には広告(アフィリエイトリンク)を含む場合があります。詳しくはこのサイトについてをご覧ください。
結論
  • 働く(雇用でも個人事業でも)にはTFN(税番号)が必須
  • 申請しないまま働くと、給与から最高税率で源泉徴収される
  • TFN申請 → myGov登録 → 雇用主へ提出、の順で渡航後できるだけ早く済ませる

オーストラリアで働く(雇用でもUber Eats等の個人事業でも)には、TFN(Tax File Number、日本のマイナンバーに近い税務上の番号)が必要です。これを後回しにすると、給与から最高税率で源泉徴収されるという実害があるため、渡航後できるだけ早く済ませておきたい手続きの一つです。

TFN申請の流れ

  1. オーストラリア国税庁(ATO)の公式サイトから、オンラインでTFN申請を行う(無料)
  2. ビザ情報の確認が行われる(パスポート番号・ビザの種類等を入力)
  3. 申請後、発行まで一定の日数がかかる(数週間程度かかることがあるため、余裕をもって早めに申請する)
  4. 発行されたTFNは書面で郵送される。到着後の住所が確定してから申請する方が受け取りやすい

myGovアカウントとの関係

myGovは、ATO(税務)やMedicare等、複数の政府サービスに一括でアクセスできるポータルサイトです。TFNを取得したら、myGovアカウントを作成してATOのサービスにリンクさせておくと、確定申告(タックスリターン)の際にオンラインで完結できるようになります。myGovへのログイン・登録時にはSMS認証が必要になる場面があるため、現地の電話番号(+61)を用意しておくとスムーズです(SIMの選び方は別記事で解説しています)。

TFNを雇用主に伝えないとどうなるか

雇用開始時に「TFN declaration」というフォームで雇用主にTFNを伝える必要があります。これを提出しないまま働くと、給与から通常より高い税率で源泉徴収され、確定申告で還付を受けるまで手取りが目減りした状態が続きます。ワーホリで来てすぐ働き始めたい場合ほど、TFN申請を後回しにしないことが大切です。

まとめ

TFN申請 → myGov登録 → 雇用主への提出、という順番を渡航後の早い段階で済ませておくと、手取り額で損をせずに働き始められます。発行までに時間がかかることを見込んで、住所が決まり次第すぐに申請するのがおすすめです。

※申請手順・所要日数はATOの制度変更により変わることがあります。申請前に必ずATO公式サイトの最新情報をご確認ください。
